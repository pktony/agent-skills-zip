# 브랜치

- `main` = 프로덕션. 직접 커밋하지 않고, 작업 브랜치 머지로만 바뀐다
- 작업 브랜치는 `feat/<이름>` · `fix/<이름>` (영문 소문자 kebab-case, 주제 하나)
- 새 작업은 항상 `main` 으로 이동 → 최신화(`git pull --ff-only`) → 새 브랜치. 작업 브랜치에서 바로 따지 않는다. 미병합 커밋이 딸려 간다
- 현재 브랜치와 상관없는 작업은 별도 브랜치로 분리한다. 미커밋 변경은 커밋 · stash 로 정리한 뒤 이동한다. 변경을 둔 채 브랜치를 오가지 않는다
- 브랜치 1개 = 주제 1개. 상관없는 변경을 "김에" 같이 커밋하지 않는다
- `main` 머지는 요청할 때만, `--no-ff` 로. 충돌은 멈추고 보고한다
- 프로젝트에 git-flow 스킬이 있으면 그 절차를 따른다
