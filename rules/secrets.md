# 설정 · 비밀값

- 민감한 값 · 운영 중 바꿀 값은 전부 환경변수. 코드에 리터럴로 박지 않는다
- 운영은 비밀 저장소(SSM Parameter Store · Secrets Manager) + 인스턴스 역할로 읽는다. 파일로 떨어뜨리지 않는다
- API 키는 요청 헤더 외 어디에도 남기지 않는다: DB 컬럼 · 로그 · 에러 메시지 금지
- 서명 키 같은 비밀은 기본값을 두지 않는다. 빈 값으로 서명하면 누구나 토큰을 만든다. 없으면 부팅이 실패해야 한다
- 프로세스마다 필요한 값만 준다 (DB URL 은 DB 를 쓰는 프로세스에만)
- 규약에서 벗어난 선택을 했으면 배포 문서에 이유와 함께 적는다
