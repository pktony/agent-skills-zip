# web 계층 · 상태

계층은 위에서 아래로 한 방향이다.

| 층 | 하는 일 | 하지 않는 일 |
|---|---|---|
| `app/` | 라우팅. view 1개 렌더 | 마크업 · 상태 · 데이터 로딩 |
| `views/` | 도메인을 넘는 화면 조립 | 도메인 규칙 · API 호출 |
| `domains/<d>/` | 스키마 · API · 컴포넌트 · 훅 | 다른 도메인 내부 참조 |
| `shared/` | API 클라이언트 · 쿼리 인프라 · UI 프리미티브 · 디자인 토큰 | 도메인 지식 |

상태는 출처로 나눈다. 섞지 않는다.

- 서버 상태는 TanStack Query(`domains/<d>/use-*.ts`), 클라이언트 상태는 zustand(`*.store.ts`)
- 서버 상태를 `useState` 로 복사하지 않는다. 갱신은 뮤테이션 `onSuccess` · `invalidateQueries`
- 쿼리 키는 한 파일(`shared/query/keys.ts`)이 SSOT. 호출 지점에서 키 문자열을 만들지 않는다
- 진행 중 작업은 폴링으로 받고, 끝나면 관련 쿼리를 무효화
- 서버가 에러 코드로 거절한 실패는 재시도하지 않는다
- 상태 · 부수효과는 `use-*.ts` 훅으로 뺀다. 컴포넌트는 배치만 한다
