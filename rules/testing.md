# 테스트

- 경계 계약(두 언어 · 두 프로세스 사이의 DTO · 저장 키 · 에러 코드)은 정답표 대조 테스트로 지킨다. 회귀가 가장 먼저 깨져야 하는 곳이다
- 결정론적 픽셀 · 데이터 변환은 골든 픽스처로 검증한다. 입력과 파라미터를 고정하고 출력 해시를 비교한다
- 비결정론적 외부 호출(LLM · 이미지 생성 provider)은 테스트 경계 밖. 어댑터 뒤에서 대역으로 바꾼다
- ORM 스키마가 표현 못 해 손으로 넣은 DB 객체(CHECK · 부분 인덱스)는 존재를 단정하는 테스트로 지킨다
- 배포는 테스트 통과 후에만. 각 프로젝트 검사는 CI 게이트로 건다
