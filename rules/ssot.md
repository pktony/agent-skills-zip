# SSOT

- 진실 하나 = 소유자 하나. 같은 값을 두 곳에서 계산 · 저장하지 않는다
- 프로젝트는 "진실 → 소유자" 표를 규약 문서에 든다. 새 개념을 더하면 표부터 고친다
- 운영 중 바꾸는 값은 DB 설정 테이블이 소유하고 `.env` 는 기본값이다. "행이 없으면 기본값" 판정은 스토어 한 곳만 안다. 직접 읽는 경로가 하나라도 있으면 운영자가 바꾼 값이 그 경로에서만 무시된다
- 구조 데이터는 DB, 바이트(이미지 · 파일)는 오브젝트 스토리지. 스토리지를 인덱스로 쓰지 않는다
- 저장 키 · 경로 패턴은 한 모듈이 만든다. 호출 지점에서 문자열을 조립하지 않는다
- 슬러그(키 · 프롬프트에 들어가는 이름)와 라벨(화면 이름)은 다른 칸이다. 화면 문구는 코드 상수와 섞지 않는다
- 두 언어에 걸친 계약(필드 이름 · enum · 에러 코드 · 키 패턴 · 설정 기본값)은 JSON 정답표 하나를 두고 각 언어가 미러를 들어 테스트로 대조한다. 코드 생성은 하지 않는다
